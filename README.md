# wordler
Wordler.org is a free online multilingual daily word puzzle game.
## Play Wordler Online
You can play the official multilingual game directly in your browser.

👉 *[Play Wordle Online](https://wordler.org)*

### Features:
* Free daily word puzzles.
* Support for 20+ languages.
* Multiple difficulty modes (4-11 letter words).
* Works with any device having a browser.
